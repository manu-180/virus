## 0. Insights operativos (aplicar a TODOS los carruseles)

| Insight | Implicancia |
|---|---|
| Carruseles tienen 1.92% ER vs 0.45% imagen / 0.50% reel | Es el formato top en IG 2026. Priorizar sobre reels. |
| **Slide 3 es la métrica del algoritmo** | Si el viewer no pasa de slide 2, IG no te re-distribuye. Slide 1+2 son test de oro, no warmup. |
| **Save rate** es la señal más fuerte | Cada carrusel debe tener mínimo 1 slide "guardable": checklist, framework, comparativa, plantilla, números clave. |
| 8–10 slides 1080x1350 | 6 se queda corto, 12+ pierde gente. Sweet spot 7–9. |
| CTA al final = +20–30% engagement | Nunca terminar sin un "qué hacer ahora". |
| Cover responde "¿es para mí?" + "¿qué me llevo?" en ≤10 palabras | Si la portada no contesta esas dos preguntas, no hay swipe. |
| 3 carruseles/semana de alta calidad > daily de bajo esfuerzo | Cadencia recomendada para B2B/SaaS. |

### Los 5 ganchos que más swipean en 2026 (probados B2B/SaaS)
1. **Specific number + outcome** → "Cobré $4.200 USD por una landing en 6 días. Acá el desglose."
2. **Contrarian / unpopular opinion** → "Tu sitio web es lo de menos. Esto es lo que importa."
3. **Confession / mistake** → "Perdí 3 clientes este año por no tener X. Aprendé del error."
4. **Curiosity gap con omisión** → "El 80% de las pymes argentinas pierde el lead acá (slide 4 te muestro dónde)."
5. **Tag-the-pain literal** → "Si tu web no convierte, esto va para vos."

### Anti-patrones detectados en lo ya publicado
- Mucho "5 cosas que…" + "5 errores que…" → fatiga de listicle.
- Casi nada de **case-study con números reales** → desperdicio de oro.
- Cero **storytelling personal** ("la vez que…") → no se está usando el formato que más comments genera.
- Cero **vs. comparativa visual lado a lado** → formato que dispara saves.
- Cero **plantillas descargables** ("comentá CODIGO y te mando el checklist") → maquina de leads no activada.

## 2. BotLode — Chatbots IA → **Pivot a AGENCIAS de marketing/web** (ICP nuevo)

### Re-posicionamiento (basado en lo que me contaste hoy)

**Modelo de negocio actual de BotLode (clarificado):**
- App **gratis** para crear chatbots.
- El **usuario real** es la **agencia de marketing / agencia de diseño web / freelance web**, no el dueño del negocio final.
- La agencia arma el bot **gratis**, lo embebe en la web de su cliente, y **al mes 1 le cobra mantenimiento** al cliente.
- Para la agencia es **revenue 100% margen** (BotLode no cobra al cliente, le cobra a la agencia el mantenimiento del bot).
- Features clave del bot que vende la agencia: **historial de conversaciones**, **alertas de notificación cuando alguien quiere comprar**, **detección de interés en leads** (lead scoring).

**ICP redefinido:** agencias de marketing digital, estudios de diseño web, freelancers web, growth hackers con 3+ clientes activos que ya cobran retainer o quieren empezar a cobrarlo.

**Pains del ICP (agencia):**
- "Mis clientes me pagan una vez la web y nunca más vuelven" → necesita recurrente.
- "Vendo Google Ads y SEO pero no tengo un producto propio que escalar" → necesita oferta empaquetada.
- "Tengo 8 clientes y manejo todo con WhatsApp / Slack / Excel" → necesita herramienta cliente-friendly.
- "Mis clientes pyme no entienden 'lead scoring' pero sí entienden 'alertame cuando alguien quiere comprar'" → necesita lenguaje de output.
- "Mostrar un dashboard al cliente me da más renovación que un PDF" → necesita reporting visible.

**Tagline candidato:** *"BotLode: armá el chatbot gratis, cobrále el mantenimiento al cliente, quedate con el 100%."*

## 4. Plantillas de copy reutilizables (para cualquier proyecto)

### Plantilla cover "is this for me?"
```
[Vertical específico] que [actividad concreta]:
[Promesa de outcome] sin [pain común].
```
Ejemplo APEX: "Pymes argentinas que venden por WhatsApp: cómo automatizar pedidos sin cambiar el modo en que ya laburás."

### Plantilla slide 2 (lograr el swipe a slide 3)
```
Si esto te suena, seguí:
- [Pain 1]
- [Pain 2]
- [Pain 3]
```

### Plantilla slide 3 (engagement-deepening)
```
La razón por la que esto pasa NO es [lo que todos creen].
Es [insight contrarian].
```

### Plantilla slide guardable (donde se gana el save)
- Checklist de 5–8 items con tick boxes.
- Tabla 2 columnas (antes / después).
- Stack con 4–6 logos.
- Framework con 3 pasos numerados.
- Plantilla descargable: "comentá 'GUIA' y te la mando".

### Plantilla CTA final
```
Si te sirvió:
1) Guardalo (lo vas a necesitar)
2) Mandáselo al [persona específica] que sabés que lo necesita
3) [CTA dura: WhatsApp / sumate a la lista / pedí demo]
```
